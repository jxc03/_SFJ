# _SFJ
Personal food review blog/website 

## Development Methodology
1. Protoype - Mock/Design the layout, pages and user experience.
2. Implement - Develop a small, working version or develop the first iteration of the blog/website.
3. Test and Document - Verify the behaviour, record what was implemented and why/explanation.
4. Evaluate and Improve - Identify changes, new requirements and improvements.
5. Repeat for the next iteration.

## The First Version Core Features
| Feature | Purpose|
|---|---|
| Homepage             | Introduction to website, showcase featured and recent reviews |
| Review listings      | Browse through published reviews with photos, titles and ratings |
| Individual reviews   | Detailed experience, photos, videos, ratings, order and prices |
| Eatery information   | Name, food category, address, location, opening information and website links |
| Search and filtering | Search reviews or filte rby location, cuisine, food and rating |
| Admin management     | Privately create, edit publish and delete content |
| About and contact    | Introduce, way for visitor to contact and link to other social |
